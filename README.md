# سامانه هوشمند تحلیل و پایش ترافیک جاده‌ای (AI Traffic Vision)

سامانه **AI Traffic Vision** یک نرم‌افزار کامل، ماژولار و محلی برای نظارت مجاز ترافیکی، رهگیری وسایل نقلیه، تخمین فیزیکی سرعت با استفاده از کالیبراسیون سطح جاده، بازشناسی هوشمند پلاک‌های ایرانی (خودرو و موتورسیکلت) و مدیریت پرونده‌های بازبینی انسانی تخلفات سرعت بر اساس قانون ۳ اخطار مجزا می‌باشد.

> **نکته حائز اهمیت قانونی و اخلاقی:** این سامانه هرگز به صورت خودکار جریمه صادر نمی‌کند، وسیله نقلیه را تنبیه نکرده و اطلاعاتی را بدون بازبینی به مراجع ارسال نمی‌کند. ثبت ۳ اخطار صرفاً یک پرونده در انتظار بررسی انسانی ایجاد می‌کند.

## ویژگی‌ها و قابلیت‌های اصلی

- **تشخیص همزمان چند وسیله نقلیه:** شناسایی مجزای انواع خودرو، موتورسیکلت، اتوبوس و کامیون در هر فریم با مدل سبک Ultralytics YOLOv8.
- **رهگیری پیوسته چند شیء (MOT):** رهگیری پیوسته شناسه هر وسیله با الگوریتم پیشرفته ByteTrack.
- **تخمین سرعت فیزیکی مبتنی بر هوموگرافی:** محاسبه سرعت حقیقی بر حسب کیلومتر بر ساعت با استفاده از ۴ نقطه متری روی صفحه جاده و اختلاف زمانی فریم‌ها (عدم گزارش سرعت ساختگی در صورت عدم کالیبراسیون).
- **قانون رنگ‌بندی ۵۰ کیلومتر:** تفکیک قطعی سرعت (سبز برای زیر ۵۰، زرد برای دقیقاً ۵۰، قرمز برای بالاتر از ۵۰).
- **تشخیص اختصاصی پلاک ایران:** مجهز به مدل آزموده شده تشخیص پلاک ایرانی (YOLOv8 با دقت mAP ۹۸.۷٪).
- **موتور OCR نویسه‌ها و ارقام فارسی:** پشتیبانی اختصاصی از ساختار پلاک خودروهای شخصی (`DD L DDD DD`) و پلاک موتورسیکلت‌های ایران (`DDD - DDDDD`).
- **تجمیع زمانی خوانش‌ها (Temporal Consensus):** رأی‌گیری کاراکتری و رشته‌ای وزندار روی فریم‌های متوالی برای رفع لغزش OCR بدون جعل پلاک.
- **موتور اخطار چندمرحله‌ای:** الزام به پایداری سرعت غیرمجاز (۱.۵ ثانیه)، زمان خنک‌سازی (۱۰ ثانیه) و بازنشانی وضعیت سرعت برای جلوگیری از ثبت مکرر در یک قسمت پیوسته.
- **پرونده بررسی ۳ اخطار:** تشکیل پرونده بازبینی انسانی پس از ثبت ۳ اخطار مجزا برای یک پلاک تاییدشده به همراه بهترین برش پلاک و تصویر شواهد.
- **داشبورد حرفه‌ای راست‌چین (RTL) فارسی:** واسط کاربری مدرن با React ،TypeScript ،Vite و قابلیت تغییر زبان به انگلیسی.

## نیازمندی‌های سیستم و سخت‌افزار

- **سیستم عامل:** Windows 10/11 (یا Linux)
- **پایتون:** پایتون 3.10 تا 3.14 (همراه با فعال‌بودن پشتیبانی UTF-8)
- **محیط Node.js:** نسخه 18 یا بالاتر برای فرانت‌اند
- **حافظه رم (RAM):** حداقل 8 گیگابایت (16 گیگابایت توصیه می‌شود)
- **کارت گرافیک (اختیاری):** پشتیبانی از NVIDIA CUDA برای شتاب‌بخشی (به طور خودکار شناسایی می‌شود؛ در صورت نبود پردازنده گرافیکی، استنتاج بهینه روی CPU اجرا می‌گردد)
- **فضای ذخیره‌سازی:**
  - نرم‌افزار و مدل‌های سبک: حدود ۱.۵ گیگابایت
  - دیتاست‌های استاندارد پلاک و نویسه‌های ایرانیس: حدود ۱.۵ گیگابایت
  - دیتاست کامل تصاویر خودرو IR-LPR (اختیاری): حدود ۱۵ الی ۳۰ گیگابایت

## نصب و راه‌اندازی سریع در ویندوز ۱۱

### روش اول: راه‌اندازی خودکار با اسکریپت‌های Bat

1. اسکریپت راه‌اندازی اولیه را اجرا کنید:
   ```cmd
   setup.bat
   ```
   این اسکریپت پایتون و Node را بررسی کرده، محیط مجازی `.venv` را ساخته، وابستگی‌ها را نصب، دیتابیس را مقداردهی کرده و فرانت‌اند را بیلد می‌کند.

2. اجرای برنامه:
   ```cmd
   run.bat
   ```
   این دستور همزمان سرور بک‌اند (پورت ۸۰۰۰) و فرانت‌اند (پورت ۵۱۷۳) را در دو پنجره مستقل بالا آورده و مرورگر را باز می‌کند.

### روش دوم: اجرای دستی با خط فرمان

**۱. آماده‌سازی محیط پایتون:**
```powershell
$env:PYTHONUTF8=1
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

**۲. ساخت و مقداردهی دیتابیس و فولدرها:**
```powershell
python -c "from src.ai_traffic_vision.core.database import init_db; from src.ai_traffic_vision.core.config import settings; settings.resolve_paths(); init_db()"
```

**۳. راه‌اندازی بک‌اند (FastAPI):**
```powershell
uvicorn src.ai_traffic_vision.api.app:app --host 127.0.0.1 --port 8000 --reload
```

**۴. راه‌اندازی فرانت‌اند (در یک ترمینال دیگر):**
```powershell
cd frontend
npm install
npm run dev
```
سپس آدرس `http://localhost:5173` را در مرورگر باز نمایید.

## قوانین رنگ‌بندی سرعت (قانون ۵۰ کیلومتر بر ساعت)

نمایش سرعت در ویدیو و داشبورد با دقت ۱ رقم اعشار گرد شده و وضعیت رنگی دقیقاً منطبق با عدد نمایش‌داده‌شده تعیین می‌گردد:

| سرعت نمایش داده شده | رنگ وضعیت | وضعیت تخلف | توضیحات |
| :--- | :--- | :--- | :--- |
| **کمتر از ۵۰.۰** (مثلاً ۴۹.۹) | **سبز (GREEN)** | سرعت مجاز | سرعت در محدوده قانونی است. |
| **دقیقاً ۵۰.۰** | **زرد (YELLOW)** | سرعت مرزی | سرعت روی مرز مجاز قرار دارد. |
| **بیش از ۵۰.۰** (مثلاً ۵۰.۱ یا ۶۵.۰) | **قرمز (RED)** | سرعت غیرمجاز | مشمول ارزیابی پایداری اخطار. |
| **عدم کالیبراسیون** | **خاکستری (GRAY)** | نیازمند کالیبراسیون | سرعت فیزیکی گزارش نمی‌شود. |

## موتور اخطار و قانون ۳ تخلف مجزا

۱. **شرایط ثبت یک اخطار:**
   - کالیبراسیون دوربین باید معتبر باشد.
   - سرعت نمایش‌داده‌شده بالاتر از ۵۰.۰ کیلومتر بر ساعت باشد.
   - وضعیت سرعت غیرمجاز به مدت حداقل **۱.۵ ثانیه** (قابل تنظیم) مداوم پایدار بماند.
   - یک قسمت ممتد سرعت غیرمجاز فقط **یک اخطار** تولید می‌کند و فریم‌های متوالی شمارش نمی‌شوند.
   - دوره خنک‌سازی (Cooldown) به مدت **۱۰ ثانیه** رعایت می‌شود و ثبت اخطار جدید نیازمند بازگشت وسیله به سرعت مجاز (Re-arming) است.

۲. **قانون ۳ اخطار مجزا و پرونده بازبینی:**
   - با ثبت ۳ اخطار مجزا برای یک پلاک مطمئن، سامانه به صورت خودکار یک پرونده بررسی (`ReviewCase`) ایجاد می‌کند.
   - واضح‌ترین تصویر برش پلاک و فریم کامل شواهد ثبت و بایگانی می‌گردد.
   - بازبین انسانی در داشبورد می‌تواند پرونده را مشاهده کرده و یکی از وضعیت‌های زیر را با ثبت یادداشت ممیزی اعمال کند:
     - **تأیید شد (Approved)**
     - **رد شد (Rejected)**
     - **نیاز به بازبینی بیشتر (Need More Evidence)**

## نحوه کالیبراسیون پرسپکتیو دوربین

محاسبه سرعت فیزیکی حقیقی نیازمند ماتریس هوموگرافی سطح جاده است:
1. در داشبورد به تب **«کالیبراسیون پرسپکتیو»** بروید.
2. چهار نقطه روی خطوط یا علامت‌های استاندارد جاده را بر حسب مختصات پیکسل `[x, y]` وارد کنید:
   - نقطه ۱: بالا-چپ `[420, 640]`
   - نقطه ۲: بالا-راست `[880, 640]`
   - نقطه ۳: پایین-راست `[1180, 980]`
   - نقطه ۴: پایین-چپ `[140, 980]`
3. ابعاد متری واقعی آن چهارضلعی را در سطح زمین وارد کنید (مثلاً عرض خط خط‌کشی ۷.۲ متر در طول ۲۵ متر):
   - `[[0.0, 0.0], [7.2, 0.0], [7.2, 25.0], [0.0, 25.0]]`
4. دکمه **«محاسبه و ذخیره کالیبراسیون»** را بزنید. نقطه تماس چرخ‌ها (پایین-وسط کادر خودرو) مبنای تبدیل به متر و محاسبه مشتق مکانی/زمانی قرار می‌گیرد.

## خط‌مشی بازشناسی پلاک‌های ایرانی و عدم قطعیت OCR

- **پلاک خودرو شخصی:** چیدمان ۲ رقم چپ + ۱ حرف فارسی + ۳ رقم راست + کد استان ۲ رقمی (مانند `۱۲ ب ۳۴۵ ایران ۱۱`).
- **پلاک موتورسیکلت:** چیدمان ۳ رقم بالا (کد شهر/استان) + ۵ رقم پایین سریال (مانند `۱۲۳ - ۴۵۶۷۸`).
- **تجمیع زمانی فریم‌ها:** سامانه خوانش‌های متوالی را در چند فریم با هم ترکیب می‌کند. در صورتی که خوانش OCR شفاف نباشد، سامانه برچسب نامعتبر را به عنوان پلاک فرضی جا نمی‌زند و وضعیت عدم قطعیت را حفظ می‌نماید.

## راهنمای بارگیری دیتاست‌ها و مدیریت حجم

اسکریپت `scripts/download_datasets.py` وظیفه مدیریت، بررسی حجم آزاد دیسک، بارگیری با gdown و اعتبارسنجی آرشیوها را بر عهده دارد:

### مشاهده لیست و پروفایل‌ها:
```bash
python scripts/download_datasets.py --list
```

### پروفایل‌های پیشنهادی:
1. **پروفایل پلاک‌های سبک (پیشنهادی):**
   شامل تصاویر پلاک و پلاک‌های مصنوعی IR-LPR با حجم حدود ۱.۰۷ گیگابایت:
   ```bash
   python scripts/download_datasets.py --profile iranian-plates-only
   ```

2. **پروفایل نویسه‌های ایرانیس (۸۳ هزار نمونه):**
   حجم حدود ۷۰.۸ مگابایت:
   ```bash
   python scripts/download_datasets.py --profile iranis
   ```

3. **تولید پلاک‌های مصنوعی (موتور و خودرو):**
   بدون نیاز به دانلود اینترنتی، تولید محلی با برچسب YOLO:
   ```bash
   python scripts/generate_synthetic_plates.py --num-images 500
   python scripts/generate_synthetic_plates.py --num-images 500 --motorcycle
   ```

4. **بررسی سلامت و اصالت فایل‌های دانلود شده:**
   ```bash
   python scripts/download_datasets.py --verify
   python scripts/download_datasets.py --status
   ```

## English Documentation & Architecture Summary

### Core Architecture
- **Backend Framework:** FastAPI with asynchronous execution and background video threading.
- **Detector Adapter:** Ultralytics YOLOv8 with COCO vehicle mapping (car, motorcycle, bus, truck) and ByteTrack integration.
- **Plate Localization:** YOLOv8 model (`models/plate_detector/best.pt`) specialized on Iranian plates.
- **Persian OCR & Normalization:** Unicode normalization, Persian digit folding, Iranian plate grammar validation (`civilian` and `motorcycle`), and multi-frame temporal voting consensus.
- **Speed Calibration:** Planar homography converting pixel trajectories to physical metric displacements, EMA smoothing, and outlier rejection.
- **Warning Engine:** Confirmation duration (1.5s), cooldown (10s), distinct episode counting, and automated creation of human-review cases upon reaching 3 distinct warnings.
- **Frontend:** React 19 + TypeScript + Vite + custom Persian RTL design with dark theme and English toggle.
- **Database:** Persistent SQLite via SQLAlchemy with tables for cameras, calibrations, jobs, tracks, observations, events, cases, and audit logs.
